# 关于NyouOS

## 什么是 NyouOS?

NyouOS On Web 是一款完全运行在浏览器中的现代化操作系统，基于 Fluent Design 设计理念，为用户提供接近原生操作系统的完整体验。

无需下载安装，打开浏览器即可使用。支持文件管理、应用商店、AI 助手、多任务窗口管理等完整功能，让你的浏览器变成一台真正的电脑。

NyouOS 采用纯原生技术栈开发，无框架依赖，确保极致性能和流畅体验。所有数据本地存储，隐私安全由你掌控。

## NyouOS 特性
**三秒启动**:极速启动，开机即畅享。从打开到进入桌面只需短短几秒。
**Fluent Design**:毛玻璃效果、圆角设计、流畅动画，每一处细节都经过精心打磨。
**本地持久化**:localStorage 存储所有设置和数据，隐私安全完全由你掌控
**系统级 AI 助手**:Surf AI 与操作系统无缝融合，为用户在各类应用中提供智能操控体验。
**主题切换**:支持浅色/深色主题，自适应系统偏好，视觉舒适。
**云端账号同步**:Supabase 驱动，跨设备数据互通，登录安全有保障。

## 设计理念
1. NyouOS 采用简约设计，并融合 Fluent Design 美学理念，呈现直观友好的用户交互与界面。
2. 从打开到进入桌面，NyouOS 仅需短短几秒，哪怕是入门级设备也能流畅运行。招之即来，挥之则去。
3. NyouOS 所有数据保存在本地浏览器中，不经过第三方服务器，全面保障你的数据安全，让你尽享前所未有的安心体验。
